# Modelo auxiliar de detección de rostros

Archivo: `face_detection_yunet_2023mar.onnx`

Origen oficial: https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet

Descarga: https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx

SHA256: `8f2383e4dd3cfbb4553ea8718107fc0423210dc964f9f4280604804ed2552fa4`

Se ejecuta localmente como respaldo cuando Haar Cascade no encuentra rostros. Se comprueba la foto a dos tamaños para detectar también caras que ocupan casi toda la imagen. Las fotos no se envían a un servicio externo.
